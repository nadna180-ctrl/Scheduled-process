# 예정공정표 작성기

내역서 금액을 가중치로 삼아, 각 공정의 착수일~완료일 사이 작업일(평일) 수로 공정률을 나눠 월간·주간 예정공정표와 누계 공정률 곡선을 만드는 도구입니다. 결과는 A3 인쇄용 엑셀 파일로 저장할 수 있습니다.

설치할 것 없이 `index.html` 한 파일을 브라우저로 열면 바로 쓸 수 있습니다. GitHub Pages로 배포하면 링크로 공유할 수도 있습니다.

## 사용 순서

1. **공사 개요**에 공사명, 착공일, 준공일을 입력합니다.
2. **내역서 붙여넣기**로 엑셀 내역서의 공종명·금액 열을 복사해 붙여넣습니다. 합계·소계 줄은 자동으로 건너뜁니다.
3. **초안 자동 배치**를 누르면 공사기간 안에 공정 순서대로 기간이 잡힙니다. 가설·공통 공종은 전체 기간, 조경·부대·정리 공종은 후반부로 배치됩니다.
4. 각 공정의 착수일·완료일을 고치면 공정표와 누계 공정률이 바로 다시 계산됩니다.
5. 중간에 쉬는 기간이 있으면 공종 오른쪽 **+** 버튼으로 작업 구간을 나눕니다. (예: 26.12 작업 → 1~2월 휴지 → 27.3 재개)
6. **엑셀 파일 저장 (A3)**으로 인쇄용 엑셀 파일을 받습니다.

## 계산 방식

- 공종 비율 = 공종 금액 ÷ 총 공사금액
- 기간 공정률 = 공종 비율 × 해당 기간(월/주)의 작업일수 ÷ 공종 총 작업일수
- 작업일은 월~금 기준이며, 공휴일·대체공휴일 제외 여부와 토요일 작업 여부를 설정할 수 있습니다.
- 구간이 여러 개인 공종은 모든 구간의 작업일 합계로 나눠 배분합니다.
- 화면의 누계 공정률 곡선은 매주(일요일 기준) 점을 찍고, 기간 공정률은 막대로 표시합니다.

## 엑셀 파일

- A3 가로, 한 페이지 너비에 맞춤 인쇄 설정 (머리글 행 반복, 바닥글에 공사명·쪽 번호)
- 월간 표시는 한 달을 상·중·하순 세 칸으로 나눠 공정 막대를 표시
- 작업일, 기간별 공정률, 공정 막대(조건부 서식), 합계, 누계, 기성액이 모두 엑셀 수식
- 누계 공정률 곡선 + 기간 공정률 막대가 엑셀 차트로 들어가며, 표가 바뀌면 자동으로 다시 그려짐
- 「휴일」 시트에 날짜를 추가하면 작업일 계산에 바로 반영

### 엑셀에서 직접 수정할 때

- 금액(C열), 착수일·완료일(E·F열)을 바꾸면 작업일, 공정률, 막대, 합계, 누계, 차트가 모두 다시 계산됩니다.
- 작업이 없는 기간은 **막대 칸**을 지우면 그 공종의 남은 기간으로 자동 재배분되어 공종 비율과 전체 100%가 유지됩니다.
- 공종을 추가할 때는 기존 공종의 막대 줄+공정률 줄을 행째로 복사해 **복사한 셀 삽입**을 하면 합계에 자동 포함됩니다.
- 공정률 숫자 칸만 지우면 합계가 맞지 않습니다. 인쇄 범위 밖 검증 칸에 "합계 불일치"가 표시됩니다.
- 표 아래 계산용 행과 표 오른쪽 구분·곡선 계수 칸은 인쇄되지 않지만 수식과 차트가 참조하므로 지우지 마세요.
- 저장할 때의 공사기간 밖으로 날짜를 옮기면 해당 칸이 없어 반영되지 않습니다. 공기 연장처럼 구조가 바뀌는 수정은 화면에서 고친 뒤 다시 저장하세요.

## 참고

- 입력 내용은 사용 중인 브라우저(localStorage)에만 저장됩니다.
- 기본 공휴일 목록(2026~2027년)은 정부 발표에 따라 달라질 수 있으니 확인 후 사용하세요.
- 엑셀 생성에는 [ExcelJS](https://github.com/exceljs/exceljs)와 [JSZip](https://stuk.github.io/jszip/)을 CDN에서 불러오므로, 엑셀 저장 시 인터넷 연결이 필요합니다.
